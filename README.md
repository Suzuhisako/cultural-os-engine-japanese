# カルチャーOS分析アプリケーション ( Cultural OS Analysis App)　ーー 日本語版ーー

AI（Gemini API）を活用して、ターゲット国における「コーポレートOS（企業文化・組織風土）」と「エブリデイOS（日常生活・国民性）」のギャップを多角的に分析・マトリクス化し、PDFレポートとして出力できるカルチャー分析ツールです。

海外進出、ローカライズ戦略、またはグローバルチームのマネジメントにおける文化的な摩擦（コンフリクト）を事前にシミュレーションし、視覚的に把握することを目的として開発されました。

---

## 🌟 主な機能 

* **AIシナリオ分析 & 分類**: ユーザーが入力したビジネスシナリオ（例：交渉、評価、M&Aなど）を基に、Geminiモデルが文化的背景をディープに分析。
* **日本語最適化ダッシュボード**:
    * シナリオカードの動的ナンバリング機能。
    * 国名による**あいうえお順（日本語辞書順）**でのスムーズなソート機能。
    * 直感的な「分析マトリクスを開く」リンクによる詳細画面への遷移。
* **XHTML2PDFによる日本語PDFレポート出力**:
    * 明瞭で読みやすい「平成角ゴシック（HeiseiKakuGo-W5）」フォントを強制インジェクション。
    * CJK（中国語・日本語・韓国語）特有の改行バグを自動修正するプロパティを内蔵し、美しいレイアウトでダウンロード可能。

---

## 🛠️ 技術スタック 

* **Backend**: Python 3.x / Flask
* **AI Engine**: Google GenAI SDK (`gemini-2.5-flash`)
* **Frontend**: HTML5 / Tailwind CSS / Vanilla JavaScript
* **PDF Engine**: `xhtml2pdf` (CJKラッピングパッチ適用済)

## 🚀 セットアップと起動方法 

### 1. リポジトリのクローン
```bash
git clone [https://github.com/あなたのユーザー名/cultural-os-analysis-app.git](https://github.com/あなたのユーザー名/cultural-os-analysis-app.git)
cd cultural-os-analysis-app

2. 依存パッケージのインストール
Bash
pip install -r requirements.txt

3. 環境変数の設定 (重要 ⚠️)
セキュリティ保護のため、APIキーなどの機密情報はコード内に直接記述せず、.env ファイルを作成して管理してください。

プロジェクトのルートディレクトリに .env ファイルを作成し、以下のように記述します：

Plaintext
GEMINI_API_KEY=あなたのGoogle_Gemini_APIキー
GOOGLE_CLOUD_PROJECT=あなたのGoogle_Cloud_プロジェクトID

Note: .gitignore に必ず .env が含まれていることを確認し、GitHub上に秘密鍵が公開されないようご注意ください。

4. アプリケーションの起動
Bash
python app.py
ブラウザで http://127.0.0.1:5000 にアクセスすると、ダッシュボードが開きます。

⚙️ 開発のこだわり（デバッグの軌跡）
このアプリケーションは、単なるテキスト出力ツールに留まらず、実用的なUI/UXを実現するために以下のフロントエンド・バックエンドの調整を行っています。

ブラウザキャッシュの制御（戻るボタン対策）:
分析マトリクス画面からブラウザの「戻る」ボタンでダッシュボードに戻った際、国名が英語に戻ってしまうブラウザキャッシュの挙動を、JavaScriptの pageshow イベントリスナーでインターセプトし、常に日本語表示を維持するように固定しました。

データ型の不一致（Type Safety）ガード:
AIから返却されたデータやデータベースから読み込んだ値が、意図せずリスト型（Array）として処理されてPDFエンジンがクラッシュするのを防ぐため、Pythonの isinstance(..., list) による厳格な型安全ガードを実装しています。

日本語コンポーネントソート:
データベース上の英語名（czech, france 等）のままアルファベット順にソートされるのを防ぐため、内部に隠しひらがなマップ（ちぇこ, ふらんす）を構築。localeCompare('ja') を用いて、画面上は漢字・カタカナのまま、完璧な「あいうえお順」での並び替えを実現しました。
